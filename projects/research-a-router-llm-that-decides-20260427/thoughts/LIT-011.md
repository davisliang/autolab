## Summary

Shnitzer et al. (2023) formulate LLM routing as a set of binary classification problems: for each candidate LLM, train a correctness predictor that takes an input embedding and outputs a probability that the model answers correctly. Features are sentence-transformer embeddings (all-MiniLM / SBERT); classifiers are kNN on those embeddings. Routing then selects the model predicted to be most likely correct on the new query.

Evaluation on 29 HELM datasets (QA, reasoning, summarization) and MixInstruct shows consistent improvement over any single model. The paper directly investigates OOD generalisation of correctness predictors – a key concern for HYP-003's MMLU held-out setup.

## Key Claims

1. Repurposing benchmark evaluation data (input embeddings + correctness labels) as supervised signal for lightweight routers is effective and avoids expensive per-model inference at test time.
2. Sentence-transformer embeddings + kNN is a strong non-parametric baseline that generalises to new tasks.
3. Three routing scores are proposed; the third (uncertainty-aware) is best when the correctness predictor is imperfect on OOD data.
4. Routing smaller LLMs together can match or exceed a single large model at lower cost.

## Relevance to HYP-003

This is the most directly relevant prior work. It uses sentence embeddings as the primary feature signal and lightweight classifiers (kNN / logistic regression variant), exactly as HYP-003 proposes. HYP-003 extends this by combining semantic embeddings with syntax features (token count, vocabulary entropy, task type), which is not done in this paper. The 85% oracle accuracy threshold in HYP-003 should be compared against the accuracy levels reported here on MMLU/HELM subsets.
