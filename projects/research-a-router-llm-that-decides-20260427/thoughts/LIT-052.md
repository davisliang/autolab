## Summary

The DSC (Diverse, Simple, Categorized) benchmark evaluates commercial and open-source LLM routers across a broad spectrum of query types, including simple/easy queries deliberately chosen so that weak models perform equivalently to strong models. The paper reveals systematic fragility in routing based on category heuristics rather than query complexity.

## Key Findings Relevant to HYP-005

### Anthropic's Haiku/Sonnet 2-Tier Router Performance
The paper directly evaluates Anthropic's production router (Claude 3 Haiku / 3.5 Sonnet):
- MT-Bench Math: 80% → Sonnet (strong) — over-routes for math category
- MT-Bench Code: 50% → Sonnet — mixed performance
- SimpleCode: 30% → Sonnet — appropriately routes easy code to Haiku
- LeetCode-Easy: 7% → Sonnet — successfully routes most easy coding to Haiku
- SimpleMath: 64% → Sonnet — over-routes for math category
- MT-Bench Writing: 70% → Sonnet — significant over-routing for writing

Conclusion: Anthropic's binary router partially discriminates on complexity for code, but still over-routes for math and writing categories. This represents the real-world state of the binary Haiku/Sonnet 2-tier system.

### Category vs. Complexity Routing
Open-source BERT/MF routers are dramatically worse: they route 100% of math and coding to the strongest model regardless of difficulty (even trivial SVAMP problems or simple Python code). These systems demonstrate category-based routing, not complexity-based routing.

### Implication for 3-Tier Routing
Adding a third tier (Opus) to the Haiku/Sonnet binary system requires discriminating FOUR regimes instead of two (Haiku-sufficient / Sonnet-sufficient / Opus-required). The DSC findings suggest:
1. Even the best commercial binary router partially fails at 2-class complexity discrimination
2. 3-class discrimination is harder — the Sonnet-only zone must be reliably identified
3. However, if the Anthropic router can route 93% of LeetCode-Easy to Haiku (only 7% to Sonnet), it demonstrates complexity-based routing IS achievable for coding tasks

This evidence supports HYP-005's falsification condition: if 3-class classification is harder, the Sonnet-only zone may be too small or too misclassified to yield ≥3pp Pareto gain.
