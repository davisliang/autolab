## Summary

Gibbs & Candes (NeurIPS 2021) develop an online wrapper for conformal prediction that provably maintains target coverage frequency even when the data-generating distribution varies arbitrarily over time. The threshold is treated as a single scalar parameter θ_t updated each step via a signed-error gradient: θ_t = θ_{t-1} + γ(α - 1[miss_t]), where α is target error rate and γ is step size. No assumption on how the distribution shifts is required.

## Key Claims

1. **Provable long-run coverage**: Under any data-generating process, adaptive conformal inference achieves the target coverage frequency averaged over time — the first such guarantee without exchangeability.
2. **Single-parameter simplicity**: The update rule is a step toward target error rate, akin to a proportional controller on calibration error. No retraining, no held-out validation set beyond the streaming data.
3. **Empirical robustness**: Tested on two real datasets with visible and significant distribution shifts; prediction sets remain calibrated throughout, while standard conformal inference degrades badly.
4. **Black-box compatibility**: Works with any model outputting point predictions or quantile estimates — no access to model internals needed.

## Relevance to HYP-004

HYP-004 proposes updating cascade routing thresholds on a rolling 100-query window via gradient descent on cross-entropy loss. This paper is the theoretical backbone for why such online updates work:
- HYP-004's rolling window cross-entropy gradient ≈ a richer version of this signed-error update
- The paper shows updates provably converge even under unknown MMLU→GSM8K domain shifts
- The simpler signed-error update (this paper) vs. cross-entropy gradient (HYP-004) is an experimental lever worth testing
- Step size γ corresponds to HYP-004's learning rate; the paper gives heuristics for setting γ
