## Relevance to HYP-005

FORC is the closest prior work to HYP-005's experimental design: it uses a multi-tier pool (4 LLMs), assigns each query to the cheapest sufficient model using a learned classifier, and reports cost savings vs the strongest model. This is a generalization of HYP-005's 3-tier setup.

Key aspects relevant to HYP-005:
- **Multi-tier baseline**: FORC's 4-model pool implicitly shows that intermediate models (the 2 middle-cost LLMs) contribute to the Pareto frontier — otherwise routing would collapse to binary.
- **Metric alignment**: FORC measures cost reduction at matched quality, the exact metric HYP-005 uses (matched-cost accuracy improvement).
- **Gap from HYP-005**: FORC does not compare its 4-tier setup against a binary (smallest + largest only) baseline. HYP-005 explicitly targets this comparison.

FORC's 63% cost reduction (vs always using the largest model) is weaker than FrugalGPT's 98%, likely because FORC uses pre-routing without model outputs — directly analogous to HYP-005's design.
