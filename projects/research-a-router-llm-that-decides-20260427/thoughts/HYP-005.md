## Motivation

Every prior routing paper (FrugalGPT, RouteLLM, HybridLLM, RouterBench, AutoMix) studies *binary* routing: one weak model and one strong model. The IDEA-001 seed explicitly targets a 3-tier hierarchy (Haiku/Sonnet/Opus), and all four existing hypotheses (HYP-001 through HYP-004) assume the 3-tier design is beneficial. But this assumption is untested.

**The question conspicuously absent from the literature**: Does adding a middle tier (Sonnet) actually improve the cost-quality Pareto frontier, or does it add classification complexity without meaningfully expanding the achievable tradeoff space?

This matters because:
1. A middle tier only helps if there exists a non-trivial query population that: (a) Haiku gets wrong, (b) Sonnet gets right, AND (c) Opus does not need to be called.
2. If this "Sonnet-only zone" is small or hard to predict reliably, a binary router may dominate after accounting for 3-class classification error.
3. No benchmark (including RouterBench's 11-model setup) has isolated and quantified the Pareto advantage of adding intermediate model tiers.

## Proposed Experiment Design

**Dataset**: MMLU 5-shot (1000 query subsample, stratified by subject).

**Oracle labels**: Simulate routing by assigning each query to the cheapest model that answers it correctly, using pre-generated answers for Haiku-equivalent (distilbert proxy), Sonnet-equivalent (medium LLM proxy), and Opus-equivalent (large LLM proxy) from RouterBench or local inference. Compute per-query minimum-cost correct assignment.

**Routers under test**:
- Binary 2-tier: logistic regression classifier on sentence embeddings (route to Haiku or Opus)
- 3-tier: same architecture, 3-class output (Haiku / Sonnet / Opus)
- Comparison: at matched expected cost budgets (sweep α ∈ [0, 1]), record accuracy

**Pareto analysis**: Plot cost-quality curve for both routers. Test whether 3-tier Pareto-dominates 2-tier at ≥1 operating point by ≥3pp accuracy.

**Baseline**: Always-Haiku (lower bound), Always-Opus (upper bound), binary RouteLLM-style BERT router.

## Why This Is Novel

All prior work on LLM routing either (a) studies binary routing only, or (b) studies multi-tier cascades without comparing against binary alternatives at matched cost. No paper has drawn the Pareto frontier for both binary and ternary routing on the same dataset to determine whether the middle tier earns its complexity.

## Pre-registration Contract

- **Metric**: accuracy improvement of 3-tier over 2-tier routing at the cost operating point where 3-tier improvement is maximized, on MMLU 1000-query held-out set
- **Threshold**: ≥3.0 percentage points
- **Direction**: greater (3-tier strictly better than 2-tier at ≥1 cost operating point)
- **Falsification criterion**: If the 3-tier Pareto curve does not strictly exceed the 2-tier curve by ≥3pp at any matched-cost operating point, the hypothesis fails — implying the middle tier adds complexity without Pareto benefit, which would be a significant negative result arguing against the 3-tier design.
