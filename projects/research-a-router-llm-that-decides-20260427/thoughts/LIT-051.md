## Relevance to HYP-001

HYP-001 proposes a DistilBERT-based 3-class classifier (Haiku/Sonnet/Opus) trained on oracle correctness labels. ZOOTER provides the closest prior art for this training paradigm — using reward model scores (silver labels) rather than run-all-and-check oracle labels.

**Key quantitative findings directly informing HYP-001:**
- 86M parameter classifier trained with silver supervision achieves meaningful routing quality across 26 diverse tasks
- Routing function introduces "minor computation overhead" vs single LLM inference — validates HYP-001 core cost argument
- Tag-based label smoothing (category-aware oracle labels) is critical for overcoming label noise
- Gap between ZOOTER and oracle routing is largest on knowledge benchmarks (MMLU, GSM8K, HumanEval) — suggesting oracle labels as in HYP-001 would be more effective for these tasks

**Why HYP-001 differs from ZOOTER:**
1. HYP-001 uses correctness-based oracle labels (cheapest model achieving ≥90% of Opus quality), not RM scores — harder to get but more accurate for MMLU
2. HYP-001 specifically eliminates Haiku-as-router overhead; ZOOTER focuses on complementary expertise among same-size models
3. HYP-001 is 3-class (Haiku/Sonnet/Opus tier selection); ZOOTER routes among 6 peer-level models

**Key implication for novelty:** ZOOTER validates the mechanism but does not subsume HYP-001. The distinction: correctness-based oracle labels > reward model labels for factual QA tasks like MMLU.
