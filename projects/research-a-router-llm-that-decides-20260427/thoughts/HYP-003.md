## Motivation

Routing decisions depend on latent query properties: topical difficulty, reasoning depth, factual recall vs. multi-step inference. Single-signal approaches miss complementary information. A multi-signal ensemble drawing from:

1. **Semantic embedding similarity** to easy/hard query exemplar clusters (k-means on training set)
2. **Surface complexity features**: token count, punctuation density, average word length
3. **Vocabulary entropy**: type-token ratio as proxy for domain specificity
4. **Task-type prediction**: one-hot {factual, reasoning, coding, creative} from a small task-type classifier

…should outperform single-signal approaches and approach oracle routing accuracy.

## Claim

A logistic regression model trained on the above four signal groups achieves ≥85% routing accuracy against oracle labels on the MMLU held-out test set (20% split). Oracle label = cheapest model (Haiku < Sonnet < Opus) that achieves ≥90% of Opus score on each individual question.

## Baseline Comparison

- Always-Haiku routing accuracy: ~60% (cheap but misses hard queries)
- Always-Sonnet: ~70% correct routing (quality-safe but overspends on easy queries)
- Length-only router: ~72% routing accuracy (estimated)
- Multi-signal LR: predicted ≥85%

## Why Logistic Regression?

- Interpretable: coefficients reveal which signals matter most (useful for ablation narrative)
- Zero inference overhead at routing time
- Ablation over signal groups isolates each feature group's contribution

## Experimental Design Notes

- Features: (a) cosine sim to 3 k-means cluster centroids from training set, (b) log-normalized token count, (c) type-token ratio, (d) stopword fraction, (e) task type one-hot (4 classes from zero-shot DistilBERT)
- Embeddings: sentence-transformers/all-MiniLM-L6-v2 (fast, local, no API cost)
- Oracle labels: computed by calling Haiku/Sonnet/Opus on each question; cheapest scoring ≥0.9 × Opus_score
- Model: sklearn LogisticRegression, 5-fold CV on training set
- Seeds: 3 different train/val splits
- Evaluation: overall routing accuracy vs. oracle; per-class breakdown

## Open Questions

- Which of the four signal groups contributes most to accuracy?
- Does routing accuracy correlate with cost efficiency in practice?
- Can we identify a minimal feature set with ≥80% accuracy for lighter deployment?
