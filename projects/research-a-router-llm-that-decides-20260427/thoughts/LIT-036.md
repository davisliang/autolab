## Why This Matters for HYP-001

This paper critically frames offline classifier-based routing (HYP-001's approach) as having two production limitations:
1. **Latency overhead**: KNN and BERT classifiers add non-trivial inference latency per routing call
2. **Retraining cost**: model changes require full classifier retraining

This is relevant context: HYP-001 should acknowledge that DistilBERT routing overhead (even self-hosted) is not zero. The paper's 1.85x cost efficiency improvement suggests there's room for improvement over both LLM-as-router and offline classifier baselines via training-free approaches.

## Implication for HYP-001 Framing

HYP-001 claims cost efficiency gain over Haiku-as-router. This paper implicitly supports the premise (offline classifiers beat LLM routers in some settings) while also showing that training-free methods can be competitive. The baseline comparison HYP-001 needs is:
1. Always-Haiku (trivial lower bound)
2. Always-Sonnet (quality upper bound)
3. Haiku-as-router (HYP-001's target baseline)
4. DistilBERT classifier (HYP-001's proposed method)
5. Training-free ANN routing (this paper's approach)

## Quantitative Benchmark

On 3 standard routing benchmarks against 8 baselines:
- 3.55x overall performance improvement
- 1.85x cost efficiency improvement
- 4.25x throughput improvement

These numbers establish that routing improvements of 2-4x are achievable, putting HYP-001's 15% gain target in context as quite conservative.
