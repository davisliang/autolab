## Summary

Ong, Almahairi et al. (2024, UC Berkeley / Anyscale) introduce RouteLLM, a framework for learning routers between a strong and weak LLM using human preference data (Chatbot Arena). They train four router architectures: a similarity-weighted kNN on BERT embeddings, a DeBERTa classifier, a matrix factorization model, and a causal LLM (Llama). Data augmentation (golden labels from GPT-4 judgements) is critical to router quality. Preference-data routers reduce calls to the strong model by 2×+ with no quality drop on MMLU and MT-Bench.

## Key Claims

1. Human preference data from Chatbot Arena provides strong signal for routing; it transfers to unseen LLM pairs.
2. BERT-embedding similarity-weighted kNN is competitive with more complex learned routers at low labelling cost.
3. Calibration thresholds must be adapted per routing pair; a single fixed threshold does not generalise.
4. Matrix factorisation captures latent query-model affinity structure beyond what pairwise embeddings encode.

## Relevance to HYP-003

RouteLLM establishes that sentence-embedding similarity (kNN variant) is a strong routing signal—consistent with HYP-003's embedding component. HYP-003 adds syntax features and task-type predictions on top, which RouteLLM does not explore. RouteLLM focuses on strong vs. weak LLM (binary), while HYP-003 targets three-way routing (Haiku/Sonnet/Opus). The 2× cost reduction at matched quality provides a performance bar to beat or match.
