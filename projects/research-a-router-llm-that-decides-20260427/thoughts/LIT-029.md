## Relevance to HYP-003

This paper provides the theoretical grounding that directly addresses CRIT-004's metric mismatch concern. Key insight: routing accuracy is a proxy for quality estimation fidelity, which directly determines cost-performance improvement.

**Chain of reasoning**: better quality estimator → better routing accuracy → better cost-quality tradeoff

This validates re-framing HYP-003's metric as cost-efficiency: improving routing accuracy is instrumentally correct, but must be reported as cost savings (cost per unit quality) rather than routing accuracy in isolation.

## Theoretical Gap HYP-003 Can Fill

The paper treats quality estimator as a black box. It does not investigate which input features produce better quality estimators. HYP-003 fills this gap by ablating signal groups (embedding vs. syntax vs. task type) to understand what drives quality estimation fidelity — a contribution not present in this paper.

The formal optimality guarantee here means: any improvement in HYP-003's estimator fidelity (routing accuracy) directly translates to a provable cost-quality improvement under the linear tradeoff objective.

## Baseline Implication

Cascade routing outperforms pure input-feature routing by a large margin. HYP-003's evaluation should include a cascade variant as comparison point — this paper provides the theoretical justification for why cascade outperforms pure routing.

## Connection to CRIT-004 Fix

CRIT-004 proposed "Reframe as cost-efficiency hypothesis with actual API cost metrics." This paper provides the formal link between routing accuracy (HYP-003's current metric) and cost efficiency (the target metric CRIT-004 demands): they are equivalent under the linear cost-quality tradeoff optimization.
