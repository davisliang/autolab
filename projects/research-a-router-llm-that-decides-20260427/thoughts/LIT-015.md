## Summary

Ong et al. (2024) train router models that select between a strong and weak LLM using human preference data from Chatbot Arena. The framework uses a win-prediction model trained on input query text and a cost threshold α controlling the quality-cost tradeoff. Four router architectures are explored: BERT-based classifier, matrix factorization, causal LM head, and SW-Instruct (similarity-weighted instruction matching) — all operating exclusively on **input-side text features**. They report >2× cost reduction with minimal quality loss on MMLU, GSM8K, and MT-Bench.

## Key Claims

1. Input-text-feature classifiers trained on Chatbot Arena preference data achieve 40–80% weak-model call rate while maintaining ≥95% of strong-model quality on MMLU.
2. Data augmentation (synthetic preference labels via GPT-4 on new datasets) significantly boosts all router architectures, especially on out-of-domain tasks like GSM8K.
3. A single trained router generalizes across different strong/weak LLM pairs without retraining, suggesting learned decision boundaries capture generalizable query-complexity features.
4. **No architecture evaluates token-level output entropy or any output-side signal from the weak model** — the gap HYP-001 proposes to fill.

## Relevance to HYP-001

RouteLLM's BERT classifier is the primary text-feature baseline for HYP-001. The comparison is direct: both route between the same strong/weak model pair with the same quality-cost tradeoff objective. RouteLLM demonstrates what input-side signals can achieve; HYP-001 claims that small-model output entropy provides a more direct, instance-specific signal that improves upon this ceiling by 5pp on quality_at_budget_normalized.
