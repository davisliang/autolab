## Summary

Hybrid LLM trains a deterministic and probabilistic router to estimate the quality gap between a small and large model for each query. The probabilistic router models the quality gap as a Gaussian distribution and routes queries where the gap is likely negative (small model matches large model). A data transformation is applied when the small model is substantially weaker. Achieves 40% fewer large-model calls with <1% quality drop on a large real-world dataset (MixInstruct).

## Key Claims

1. A probabilistic router (modeling response quality gap as Gaussian) outperforms a deterministic threshold router when the small model is close in quality to the large model.
2. A novel data transformation (clipping the gap distribution tail) improves routing when the gap distribution is highly skewed.
3. BART score (BARTScore) is an effective proxy for response quality and correlates well with human judgment for routing purposes.
4. The router can be dynamically re-tuned at test time to trade quality for cost without retraining.

## Relevance to HYP-004

Hybrid LLM is a strong supervised baseline for HYP-004's comparison: it uses BARTScore (a learned quality proxy) as the routing signal but trains the router supervisedly, not via RL. The paper highlights that the quality gap metric is inherently noisy (LLM responses are stochastic), which is a challenge RL-based routing must also handle through variance reduction (REINFORCE baseline). HYP-004's REINFORCE approach must outperform Hybrid LLM at multiple budget levels to confirm the Pareto-dominance claim.

## Limitations Noted by Authors

- Router is binary (two models only); N-way extension is not investigated.
- BARTScore is a surface-level similarity metric; may not capture semantic correctness (e.g., on MMLU math).
- Router requires offline collected responses from both models for training; not online/bandit learning.
