## Relevance to HYP-002

LLM-Blender's PairRanker is prior work closest to HYP-002's judge concept: it evaluates actual candidate outputs from multiple LLMs to select the best. Empirically validates that output-conditioned selection outperforms input-feature routing — the core premise of HYP-002.

## Key Claims

1. PairRanker (cross-attention encoder over input+output pairs) achieves highest correlation with ChatGPT-based ranking.
2. Output-conditioned selection substantially outperforms input-feature routing on MixInstruct.
3. Running all models first is expensive — LLM-Blender does not address cost minimization.
4. GenFuser merges top candidates; HYP-002 selects (not merges), so GenFuser is out of scope.

## Gap Relevant to HYP-002

LLM-Blender confirms output-conditioned selection > input-feature routing, but incurs full cost of running all models. HYP-002's contribution: output-conditioned quality *without* paying for all models — run Haiku, judge output, escalate to Sonnet only if rejected. The speculative execution framing (run cheap first, observe, conditionally escalate) is absent from LLM-Blender and is HYP-002's key novelty over this line of work.
