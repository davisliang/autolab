## Relevance to HYP-005

MetaLLM provides a complementary perspective to HYP-005: while HYP-005 tests a static 3-class classifier design, MetaLLM studies online routing over multiple LLMs via bandit learning. The key relevance:

- MetaLLM's multi-arm pool inherently creates a multi-tier setup; if binary routing were Pareto-dominant, the bandit would converge to only 2 arms. That it uses a full pool supports the premise of HYP-005.
- However, MetaLLM does not provide an explicit 2-tier vs 3-tier ablation or Pareto analysis. It shows overall multi-LLM routing improvement over single models.

HYP-005 differs from MetaLLM in: (a) pre-registered static comparison, (b) explicit Pareto frontier analysis, (c) oracle routing labels on MMLU for controlled evaluation.
