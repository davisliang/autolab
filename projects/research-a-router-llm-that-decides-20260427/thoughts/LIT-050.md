## Summary

Shnitzer et al. (2023) present the most direct prior work for HYP-003. They formulate LLM routing as per-model binary classification: for each candidate LLM, a correctness predictor takes an input sentence embedding (all-MiniLM / SBERT) and outputs P(correct). At routing time, the model with the highest predicted P(correct) is selected — a single-signal approach using only embedding features.

Evaluation spans 29 HELM tasks with multiple LLMs. They explicitly study OOD generalisation via an OOD confidence model: task-distance descriptors estimate how far a new task is from training distribution, and predicted P(correct) is down-weighted accordingly. This partially bridges routing accuracy to expected cost efficiency.

## Key Claims

1. Embedding-only kNN outperforms random routing and static model assignment across diverse task types.
2. OOD confidence modelling (task-distance-based) significantly improves routing accuracy on unseen tasks beyond naive kNN.
3. Single-signal (embedding only) router leaves systematic headroom — the gap that HYP-003 targets by adding syntax/surface features.
4. Routing correctness accuracy is the established metric; cost reduction is a downstream concern tied to the task mix's difficulty distribution.

## Relevance to HYP-003

This is the direct single-signal baseline for HYP-003. HYP-003's multi-signal LR adds: (a) surface complexity features (length, punctuation, TTR), (b) vocabulary entropy, (c) task-type one-hot encoding. The routing accuracy metric (85% vs oracle) is consistent with the established metric here. The gap to address is showing multi-signal strictly outperforms embedding-only kNN in both routing accuracy AND downstream cost efficiency.

## Limitations

- Single-signal only; no evidence syntax features help; HYP-003 directly tests this.
- Routing accuracy ≠ cost efficiency when Haiku/Sonnet/Opus cost ratios are heterogeneous.
- kNN may overfit to cluster structure; regularised LR may generalise better OOD.
