## Summary

ZOOTER (Lu et al., 2023, Alibaba) proposes reward-guided routing for LLM ensembles. A reward model scores training query-response pairs per LLM; these scores are distilled into a lightweight routing function (a small classifier) that distributes each new query to the LLM with predicted domain expertise. Tag-based label enhancement (topic/task tags) mitigates noise from reward model uncertainty. Evaluated on 26 subsets across coding, math, creative writing, instruction following, etc.

ZOOTER outperforms the best single model on average and ranks first on 44% of tasks, beating reward-model-at-inference-time methods while adding only minimal overhead.

## Key Claims

1. Per-query routing signals can be distilled from reward model scores into a lightweight function without querying the reward model at inference time.
2. Tag-based label enhancement using topic/task tags reduces routing noise from reward uncertainty — a direct analogue to HYP-003's task-type one-hot encoding.
3. The routing function architecture is flexible; logistic regression on distilled labels is competitive with more complex models.
4. Topic/task tagging provides a strong categorical routing signal that outperforms undifferentiated scoring.

## Relevance to HYP-003

ZOOTER's tag-based enhancement directly validates HYP-003's task-type one-hot encoding hypothesis: categorical task type information improves routing precision. The distillation approach (reward model → small classifier) is a stronger training regime than HYP-003's oracle-label logistic regression, but it requires a reward model. HYP-003 targets the no-reward-model setting where only correctness labels are available, making its approach complementary.

## Limitations

- Requires a reward model for distillation; HYP-003 targets reward-model-free routing.
- Tag accuracy is not reported; if task-type classification is noisy, its contribution is unclear.
- Evaluated on open-domain LLM ensembles; cost/API setting differs from Haiku/Sonnet/Opus routing.
