## Summary

RouteLLM trains several supervised router architectures (matrix factorization, BERT-based classifiers, similarity-weighted random) using human preference data from Chatbot Arena. The framework reduces API cost by 2x+ while maintaining >90% of strong-model (GPT-4) quality on MMLU and MT-Bench.

## Key Claims

1. Routers trained on preference data generalize out-of-domain without retraining, even to model pairs not seen during training.
2. Data augmentation (adding synthetic preference labels from weaker judge models) significantly boosts performance across all router architectures.
3. The matrix factorization router achieves the best APGR (average performance gap recovered) on MT-Bench and MMLU at matched cost levels.
4. All supervised routers significantly outperform random baselines but none yet uses RL or direct reward optimization — leaving RL-based routing as an unexplored direction.

## Relevance to HYP-004

This is the primary **supervised baseline** that the RL-trained router in HYP-004 must Pareto-dominate. RouteLLM's APGR and CPT metrics are the gold-standard comparison points. The paper shows supervised routing achieves ~2x cost reduction but does not attempt direct reward optimization, confirming the gap the hypothesis addresses.

## Limitations Noted by Authors

- Requires curated human preference data (expensive to collect for new domains).
- Binary routing only (strong vs weak); no native N-way routing across Haiku/Sonnet/Opus.
- Threshold α must be set per quality target; no single policy spans the full Pareto frontier.
