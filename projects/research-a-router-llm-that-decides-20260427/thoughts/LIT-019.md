## Relevance to HYP-002

FrugalGPT is the primary prior-work cascade HYP-002 must outperform on GSM8K cost savings. It learns which LLM combinations to use per query via a scoring function over input features. Routes before generation — the core weakness HYP-002 addresses.

## Key Claims

1. LLM cascade matches GPT-4 with up to 98% cost reduction or improves GPT-4 by 4% at the same cost.
2. Routing based on input features + learned quality estimators — cannot observe actual output quality.
3. Bimodal difficulty distributions (like GSM8K math) are most amenable to cascade routing.
4. Three cost-reduction strategies: prompt adaptation, LLM approximation, and LLM cascade.

## Gap Relevant to HYP-002

FrugalGPT routes based on input features before any model generates output — necessarily making routing errors on ambiguous queries. HYP-002's speculative execution always observes actual Haiku output before deciding to escalate, addressing this core weakness. HYP-002 predicts ≥8pp additional cost savings on GSM8K by exploiting output-visibility.
