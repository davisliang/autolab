## AutoMix — Relevance to HYP-003 (Speculative Routing)

AutoMix (Aggarwal, Madaan et al., Google/CMU/IIT Delhi 2023) represents a sophisticated sequential cascade that uses the small model's output confidence to decide escalation. It illustrates the latency cost of generate-then-verify architectures that HYP-003 avoids.

### What AutoMix does
Three-step sequential pipeline:
1. **Small model (SLM) generates** answer to query.
2. **SLM self-verifies** by evaluating consistency of its own answer with the context (few-shot entailment formulation).
3. **POMDP router** takes the noisy self-verification probabilities as partial observations and routes to the appropriately-sized next model if needed.

### Key numbers
- **>50% cost reduction** at matched performance across HellaSwag, QASPER, NarrativeQA, QuALITY, QMSUM.
- Works with black-box APIs only (no fine-tuning).
- POMDP learns from as few as 50 examples.

### Relevance gap for HYP-003
AutoMix's sequential pipeline has a fundamental latency structure:
- For escalated queries: T_wall = T_SLM + T_verify + T_LLM (three sequential steps)
- For non-escalated queries: T_wall = T_SLM + T_verify

Compare to speculative routing for non-escalated queries:
- T_wall = max(T_router, T_Haiku) ≈ T_Haiku (router overlaps with the model call)

AutoMix pays T_SLM on **every** query as a fixed overhead, even those it will escalate. Speculative routing eliminates this sequential bottleneck by running the cheap decision-maker in parallel with the cheap model — it only pays the escalation model's time on mispredicted queries.
