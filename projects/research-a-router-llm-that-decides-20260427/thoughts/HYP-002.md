## Motivation

Existing routers project query difficulty onto a single scalar ("hard" vs "easy"). But difficulty is not one-dimensional: a query can be domain-specific but unambiguous (route to Sonnet for knowledge), or creative and domain-general (route to Sonnet for generation quality), or require multi-step reasoning (route to Opus). These axes are conflated by a single score.

## Mechanism

1. **Dimension taxonomy** (4 heads, each a binary or 3-class logistic regression):
   - **Reasoning depth** (RD): requires multi-hop deduction, math, or code synthesis
   - **Domain specificity** (DS): requires rare factual knowledge (medicine, law, advanced science)
   - **Ambiguity** (AMB): query admits multiple valid interpretations
   - **Creativity** (CR): expected output is open-ended, subjective, or stylistic

2. **Feature extraction**: shared sentence-transformer embedding (all-MiniLM-L6-v2, runs locally) → 4 independent logistic heads.

3. **Routing decision table** (learned via held-out accuracy):
   - RD=1 OR DS=1 → Opus
   - AMB=1 OR CR=1 → Sonnet
   - All zeros → Haiku

4. **Label generation**: auto-label 10k FLAN/OpenHermes queries using GPT-4o as oracle for each dimension.

## Why this beats single-score routing

- Decision boundaries in 4D space are richer than a 1D threshold.
- Each head is easier to calibrate (simpler task → better precision/recall).
- Dimension decomposition surfaces interpretable routing logic for debugging.

## Experimental Setup

- Dataset: FLAN-v2 (10k calibration), MMLU + GSM8K + AlpacaEval (evaluation)
- Baseline: single-score RouteLLM classifier at matched cost budget
- Metric: routing_accuracy = fraction of queries assigned to the model that yields highest quality/cost ratio
- Seeds: [42, 123, 456]
- Expected effect: ≥3pp improvement in routing_accuracy vs. single-score baseline

## Open Questions

- Can the 4 dimensions be learned fully unsupervised (e.g., via k-means on embedding space) rather than requiring oracle labels?
- Is the decision table better learned (random forest over 4 head scores) or hand-designed?
