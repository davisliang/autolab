## Summary

RouterBench introduces a theoretical framework for evaluating LLM routing using the convex hull of the cost-quality plane. The benchmark provides 405k pre-generated inference outcomes across 11 LLMs and 8 datasets (including MMLU), enabling routing research without live inference.

## Key Findings Relevant to HYP-005

### Convex Hull Framework for Tier Analysis
RouterBench's key theoretical contribution directly addresses HYP-005. The linear interpolation property shows:

Given models A (Haiku: low cost, low quality) and C (Opus: high cost, high quality), a binary router can achieve any cost-quality point on the line segment AC. Adding intermediate model B (Sonnet: medium cost, medium quality) strictly expands the achievable Pareto region IF AND ONLY IF B lies ABOVE the line segment AC.

This is the precise mathematical condition for 3-tier to Pareto-dominate 2-tier: the Sonnet operating point (cost_sonnet, quality_sonnet) must exceed the linear interpolation of Haiku and Opus at the same cost.

### Empirical MMLU Data Available
RouterBench includes MMLU as one of its 8 datasets, with outcomes for 11 LLMs. This provides exactly the data needed for HYP-005's oracle analysis:
- Can compute the empirical Sonnet quality gain at matched cost vs the binary Haiku/Opus interpolation
- The "Sonnet zone" size can be measured: what fraction of MMLU queries have Haiku wrong and Sonnet right
- Classifier accuracy gap vs oracle gives realistic bounds on achievable 3-tier gains

### Cost Efficiency Evidence
RouterBench empirically shows that routing over multi-model pools achieves 2-5x cost savings at matched quality. This validates the routing value but does NOT specifically compare 3-tier vs 2-tier Pareto curves — the focused experiment HYP-005 proposes.

### Critical Gap
RouterBench uses embedding-based classifiers but does not isolate the specific binary-vs-ternary routing comparison. The data is available; the comparison has not been reported.
