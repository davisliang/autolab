## FrugalGPT — Relevance to HYP-003 (Speculative Routing)

FrugalGPT (Chen, Zaharia & Zou, Stanford 2023) establishes the **sequential LLM cascade** as the dominant paradigm for cost-optimized routing. It is the primary baseline that speculative routing (HYP-003) aims to outperform on latency.

### What FrugalGPT does
- **LLM cascade**: queries a ranked list of models sequentially. For each query, it invokes the cheapest model first, scores the response with a learned reliability scorer, and escalates to the next (more expensive) model only if the score is below a threshold.
- Sequential flow: `route_decision → call_model_1 → score → (if needed) call_model_2 → …`
- Learns which list of LLMs to use per query type via a specialized constrained optimizer.

### Key numbers
- Up to **98% cost reduction** vs GPT-4 at matched performance.
- Up to **+4% accuracy** improvement at same cost.
- Evaluated across HellaSwag, HEADLINES, and Open Q&A datasets.

### Relevance gap for HYP-003
FrugalGPT's pipeline is fully sequential: the routing decision (scoring function) is computed *after* the first model responds, not *before* or *in parallel with* it. This means:
- Latency for a correctly-routed query = T(model_1) + overhead
- Latency for an escalated query = T(model_1) + T(scoring) + T(model_2) + overhead

HYP-003's speculative routing fires the Haiku call simultaneously with the router, collapsing the `T_router + T_Haiku` bottleneck into `max(T_router, T_Haiku)` for correctly-routed queries. FrugalGPT has no analogous mechanism.
