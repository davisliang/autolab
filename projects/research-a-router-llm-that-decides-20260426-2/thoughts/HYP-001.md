## Motivation

Existing routing approaches typically rely on heuristics (token count, keyword matching) or expensive meta-models. A probing classifier trained on frozen embeddings is cheap to inference and avoids training instability. The key insight is that semantic complexity is already encoded in generic sentence embeddings — we just need to extract and calibrate it.

## Method

1. Encode each query with a frozen all-MiniLM-L6-v2 (22M params, ~0.5ms CPU).
2. Train a 2-layer MLP (hidden_dim=128) to classify queries into 3 tiers: simple (→ Haiku), medium (→ Sonnet), hard (→ Opus).
3. Labels derived from "oracle" routing: the cheapest model that achieves quality ≥ Sonnet's quality on a calibration split.
4. Inference: embed → MLP → argmax → call appropriate model.

## Prediction

- Metric: `cost_per_quality_point` = (total API cost) / (aggregate quality score)
- Threshold: ≥5% lower than always-Sonnet baseline
- Direction: `less` (lower is better)

## Confounders to control

- Same temperature across all models.
- Quality measured as exact-match or normalized score on MMLU 5-shot.
- Cost measured using current Anthropic API pricing ratios (Haiku:Sonnet:Opus ≈ 1:5:25).
