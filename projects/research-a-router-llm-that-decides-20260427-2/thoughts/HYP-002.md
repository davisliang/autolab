## Hypothesis HYP-002: Confidence-Cascade Router (Cross-Domain Transplant from ASR)

### Cross-Domain Origin
Automatic Speech Recognition systems use **confidence-based cascading**: a fast acoustic model transcribes first; if its posterior confidence is below a threshold, a slower, more powerful model is invoked. This strategy — pioneered in systems like Google's two-pass end-to-end ASR — dramatically reduces compute without sacrificing accuracy. We transplant this to LLM routing.

### Claim
Rather than routing *before* inference, a cascade router lets the small model (proxy for Haiku) attempt the query first and emit a confidence signal (token-level log-probability, entropy over the vocabulary at the final token, or a lightweight verifier head). If confidence < threshold, escalate to the medium or large model. This "attempt-then-escalate" paradigm outperforms static upfront routing by ≥15% on cost-normalized quality (CNQ = quality / relative_cost vs always-large).

### Why Cascade > Static for This Domain
Static routers must judge complexity *without seeing* a partial answer. A cascade sees the model's actual attempt, which is a much richer signal. The small model's confusion (high entropy, repeated tokens, hedging phrases) is a reliable indicator that a harder model is needed.

### Experimental Setup
- **Dataset**: Same stratified sample as HYP-001 (MMLU, GSM8K, MT-Bench, HellaSwag) with pre-cached model responses.
- **Cascade signals**: (a) mean log-prob of response tokens, (b) response entropy, (c) presence of uncertainty hedges ("I'm not sure", "It depends").
- **Thresholds**: swept via dev-set calibration using Platt scaling.
- **Baseline**: HYP-001's GBDT static router and a length-threshold router.
- **Metric**: CNQ = (routed_quality / always_large_quality) / (routed_cost / always_large_cost). Higher is better.

### Pre-registered Prediction
- **metric**: `cost_normalized_quality_improvement_over_static_router` — CNQ(cascade) - CNQ(best_static_router), measured on held-out test split.
- **threshold**: 0.15 (15 percentage-point improvement in CNQ)
- **direction**: greater

### Ablation Design
Remove the cascade element: instead use the same confidence signal but as an *upfront* feature to a static router. If cascade is the mechanism, static use of the same signal should underperform cascade by at least 10pp CNQ.
