## LLM-Blender (Jiang et al., 2023)

LLM-Blender is an ensemble framework for LLMs using two modules: PairRanker (pairwise cross-encoder to rank N candidate outputs) and GenFuser (generative fusion of top-K ranked candidates). Unlike routing, it queries all N models per input and fuses results, incurring N× cost. Introduces MixInstruct benchmark with oracle pairwise comparisons for 100K instructions.

**Relevance to HYP-004**: LLM-Blender is listed in HYP-004 as a baseline to contrast with. It represents the "query all" extreme of the quality-cost tradeoff space — maximum quality but maximum cost. The key distinction from HYP-004's RL router: (1) LLM-Blender uses all models every time (no cost savings from routing), (2) PairRanker uses supervised pairwise preference training, not RL. The MixInstruct dataset and BARTScore/BERTScore quality metrics used in LLM-Blender are relevant for constructing the quality labels used in HYP-004's reward function.

**Key claims**:
1. Pairwise comparison ranking (PairRanker) outperforms pointwise ranking for subtle quality differences.
2. Optimal LLM varies significantly across queries (21% for best single model vs 100% oracle).
3. LLM-Blender achieves best MixInstruct scores but requires all N models per query — no cost efficiency.
4. MixInstruct provides 100K pairwise comparison labels useful for pre-caching quality scores.
5. No mechanism for quality-cost tradeoff; not designed as a router.
