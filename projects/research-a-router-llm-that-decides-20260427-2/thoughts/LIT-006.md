## Hybrid LLM (Mallick et al., 2024)

Hybrid LLM trains a supervised router that predicts the quality gap between a large and small LLM for each query. The desired quality level is a test-time hyperparameter that shifts routing thresholds without retraining — addressing the fixed-operating-point limitation of FrugalGPT. Two router variants: deterministic (logistic regression on quality-gap features) and probabilistic (estimates uncertainty of quality gap to handle LLM stochasticity).

**Relevance to HYP-004**: Hybrid LLM partially addresses the "fixed Pareto point" problem by making the quality threshold tunable at inference time. However, it does this by post-hoc threshold shifting, not by learning a flexible policy. HYP-004's RL approach with continuous λ is conceptually cleaner and learns quality-cost tradeoffs end-to-end. Hybrid LLM is binary (2 tiers) and supervised; HYP-004 targets 3 tiers with a learned RL policy.

**Key claims**:
1. Quality-floor threshold tunable at test time allows runtime quality-cost tradeoff without retraining.
2. Probabilistic router with data transformation handles cases where small model is significantly weaker.
3. Achieves 22–40% fewer large model calls with ≤1% quality drop on MixInstruct benchmark.
4. Binary 2-tier routing only; not extended to 3+ tiers.
5. Router trained on supervised quality-gap labels, not reward-based RL.
