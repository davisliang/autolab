## LitFinding LIT-013: FrugalGPT (Chen et al., 2023)

**Key baseline for HYP-003**: FrugalGPT is the most direct existing baseline — a learned routing cascade that uses a single DistilBERT-based scoring function to decide whether to escalate. It achieves impressive cost savings (98% on HEADLINES). However, its scorer is a single deterministic model, susceptible to overconfidence near decision boundaries (exactly the hard queries where routing errors are most costly).

**Explicit gap cited in the paper**: Section 4 notes that FrugalGPT "queries all LLMs in the chain" when it cannot confidently accept any intermediate answer — the authors acknowledge that identifying these uncertain cases is "an open problem." HYP-003 directly addresses this open problem using ensemble disagreement.

**Experimental design implications**: HYP-003 should use the FrugalGPT cascade as the single-model baseline on the OVERRULING/COQA-style hard-query subset. Cost-matched comparison is essential (ensemble inference is ~5× more expensive at scoring time).
