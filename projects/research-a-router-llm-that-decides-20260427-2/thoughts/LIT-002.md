## RouteLLM (Ong et al., 2024)

RouteLLM introduces a training framework for learning binary LLM routers that select between a strong and a weak model. Key contributions: (1) leverages human preference data from Chatbot Arena rather than synthetic labels, (2) data augmentation techniques to improve router generalization, (3) evaluates with Call-Performance Threshold (CPT) and Average Performance Gain Recovered (APGR) metrics.

**Relevance to HYP-004**: RouteLLM is the closest existing work to the routing setting in HYP-004, and is explicitly named in the hypothesis as a key baseline. RouteLLM uses only binary routing (strong/weak), trained with supervised binary cross-entropy on preference labels. HYP-004 proposes: (1) 3-way routing (small/medium/large), (2) a continuous quality-cost reward optimized via REINFORCE rather than hard labels, (3) λ-parameterized Pareto navigation at inference time. RouteLLM cannot shift operating points post-training without retraining.

**Key claims**:
1. Binary router trained on Chatbot Arena preferences reduces costs >2× with minimal quality loss.
2. Router generalizes to unseen LLM pairs without retraining.
3. APGR metric measures area under Pareto curve — directly comparable to HYP-004's CNQ metric.
4. Only supervised training; no policy gradient or reward optimization.
5. Binary routing cannot express three-tier cost granularity (Haiku/Sonnet/Opus).
