## Experiment Plan: REINFORCE Routing Policy vs Supervised GBDT

### Overview
Train a lightweight MLP router via REINFORCE with reward `r = Q(query, tier) - λ·C(tier)` and compare against a supervised GBDT baseline (HYP-001 style) that predicts the "correct" tier label. Evaluate at the operating point where quality retention ≥ 0.80 vs always-large.

### Data
- **Source**: RouterBench pre-cached outcomes (quality scores per query × tier).
- **Split**: 2000 train / 500 val / 500 test, stratified by domain (MMLU, ARC, GSM8K, HumanEval mix).
- **Quality oracle**: Normalized correctness from RouterBench (0–1 scale per query per tier).
- **Cost model**: Normalized FLOPs proxy — small=1, medium=4, large=16.

### RL Policy (Treatment)
1. Encode each query with frozen `all-MiniLM-L6-v2` → 384-d embedding.
2. MLP: 384 → 128 (ReLU) → 3 (softmax over {small, medium, large}).
3. REINFORCE with mean-reward baseline subtraction, entropy bonus (β=0.01).
4. Sweep λ ∈ {0.1, 0.3, 0.5, 1.0} to trace Pareto front.
5. 50 epochs, lr=1e-4 (Adam), batch_size=128.
6. Select λ operating point achieving quality ≥ 0.80 with lowest cost.

### Supervised Baseline
1. For each training query, assign label = cheapest tier achieving ≥ 95% of large-model quality.
2. Train LightGBM GBDT (200 trees, depth 6, lr 0.05) on same embeddings + handcrafted features.
3. At test time: predict tier directly (no threshold sweep needed; single operating point).

### Metrics
- **Primary**: `cnq_at_quality_floor_0.80` = quality_retention / cost_ratio, measured at operating point where quality ≥ 0.80.
- **Secondary**: area under Pareto curve (quality vs cost), mean reward, quality retention, cost ratio.

### Success Criterion (Pre-registered)
CNQ_rl − CNQ_supervised ≥ 0.10 (10 percentage points) at quality floor 0.80, averaged over 3 seeds.

### Sanity Gate
Overfit 32 examples for 60s; verify train loss decreases ≥ 50%.

### Ablation (auto-triggered on pass)
Remove λ·cost term (set λ=0) → policy degenerates to quality-only routing. If CNQ drops, confirms cost-quality reward shaping is the mechanism.
