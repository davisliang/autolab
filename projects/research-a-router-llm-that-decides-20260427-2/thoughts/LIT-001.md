## FrugalGPT (Chen et al., 2023)

FrugalGPT introduces a framework of three cost-reduction strategies for LLM APIs: prompt adaptation, LLM approximation, and LLM cascade. The cascade component learns which combination of LLMs (GPT-3, ChatGPT, GPT-4) to route each query to by training a scoring function (logistic regression / gradient boosted trees) on query features and cached model responses. The routing objective is budget-constrained: maximize task accuracy subject to average cost ≤ b.

**Relevance to HYP-004**: FrugalGPT is the primary supervised-routing baseline HYP-004 proposes to beat. It uses supervised classifiers with fixed operating points baked in at training time — exactly the limitation RL routing is meant to overcome. Key claims to contrast: FrugalGPT achieves 98% cost reduction at matched GPT-4 accuracy. However, this is a fixed Pareto point; no mechanism to shift the quality-cost tradeoff at inference time.

**Key claims**:
1. LLM cascade with a learned router matches GPT-4 performance at up to 98% lower cost on HEADLINES dataset.
2. The routing problem is formulated as budget-constrained quality maximization — same objective as HYP-004's λ-parameterized reward.
3. Supervised routing requires per-task retraining when quality-cost preferences change.
4. No RL or continuous-reward learning; hard routing labels from oracle tier selection.
