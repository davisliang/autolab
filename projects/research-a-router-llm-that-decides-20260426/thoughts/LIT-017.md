## Summary

FrugalGPT introduces LLM cascade: queries are forwarded through a cheapest-first list of LLMs, escalating when a learned DistilBERT reliability score falls below a threshold. The scoring function is trained on (query, answer, correctness) triplets.

## Relevance to HYP-001

Establishes the cost-savings target (98%) and formalizes cost-quality tradeoffs. However, routing is output-conditional — the cheap model must respond first. HYP-001 proposes pre-generation routing using only query-side features (token count, TTR, parse depth, task type), requiring zero model calls.

## Gap

No evaluation of whether sparse query features suffice for pre-generation routing. HYP-001 directly fills this gap.
