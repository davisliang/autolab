## Relevance to HYP-004

RouteLLM is the primary supervised routing baseline against which HYP-004 should be compared. It represents the current state of the art for data-driven routing: trained on thousands of human preference labels from Chatbot Arena. HYP-004 claims to close within 5pp routing accuracy using only self-supervised entropy labels—no human annotations required.

## Key metric alignment

RouteLLM uses "call-performance threshold" (CPT) and "average performance gain recovered" (APGR) as routing metrics. HYP-004 uses routing_accuracy on a held-out human-labeled test set. These metrics are compatible: routing_accuracy can be computed from a labeled test set that overlaps with the RouteLLM evaluation benchmarks (MMLU).

## Generalization finding is encouraging for HYP-004

RouteLLM's finding that routers generalize to unseen LLM pairs suggests that routing signals (complexity, difficulty) are model-agnostic properties of queries—lending support to HYP-004's claim that Haiku entropy labels (derived from one cheap model) can train a router that generalizes to the Haiku/Sonnet/Opus hierarchy.

## Critical open question

RouteLLM routes between exactly two models (strong/weak); HYP-004 proposes ternary routing (Haiku/Sonnet/Opus). Whether preference-data-trained binary routers can be extended to ternary routing at comparable accuracy is not addressed in RouteLLM, making the ternary extension in HYP-004 a genuine contribution.
