## Summary

LLM-Blender is an ensemble framework: PairRanker uses cross-attention to compare all N candidate outputs and select the best; GenFuser fuses the top-K. The key empirical finding is that per-query optimal model selection is extremely valuable (best single model wins only 21% of the time).

## Relevance to HYP-001

LLM-Blender's key finding — that optimal LLM varies substantially per query — directly motivates HYP-001's routing approach. The MixInstruct benchmark with oracle pairwise comparisons (100k train / 5k test) is a potential training data source for labeling routing difficulty. However, LLM-Blender is not cost-efficient (calls all N models).

## Gap for HYP-001

LLM-Blender focuses on *which model produces the best output* (post-generation), not on *predicting cheapest sufficient tier from query features alone* (pre-generation). The oracle labels from MixInstruct could be repurposed for training HYP-001's GBT classifier.
