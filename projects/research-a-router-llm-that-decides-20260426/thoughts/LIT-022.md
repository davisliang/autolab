## Summary

LLM-Blender is an ensemble framework: PairRanker selects best output from N candidates; GenFuser fuses top-K. Key finding: per-query optimal model varies substantially (best model wins only 21% of the time on MixInstruct).

## Relevance to HYP-001

Empirically motivates HYP-001's routing approach: since optimal LLM varies per query, routing is valuable. The MixInstruct oracle pairwise comparison labels could be repurposed as training signal for HYP-001's GBT classifier. However, LLM-Blender calls all N models (costly), whereas HYP-001 routes to exactly one.

## Gap

LLM-Blender focuses on post-generation selection, not pre-generation routing from query features. The oracle labels from MixInstruct could be repurposed for training HYP-001's feature-based classifier.
