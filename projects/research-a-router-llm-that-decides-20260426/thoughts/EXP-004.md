## Experiment: Self-Supervised Entropy-Router vs Supervised Router

### Overview

Test whether a router trained on self-supervised difficulty labels (derived from Haiku output-entropy) closes within 5pp routing accuracy of a fully-supervised router trained on human-annotated difficulty labels.

### Dataset Construction

Since we cannot call live LLM APIs, we construct a **synthetic routing benchmark** that faithfully captures the entropy-labeling mechanism:

1. **Query corpus** (N=2000): Sample from three proxy task distributions:
   - **MMLU-proxy** (40%): multiple-choice factual questions with varying domain difficulty. Simulated as classification instances with feature vectors encoding topic entropy + answer-option ambiguity.
   - **GSM8K-proxy** (30%): math word problems parameterized by step-count (1–8 steps). Difficulty = step-count + distractor presence.
   - **HumanEval-proxy** (30%): code-generation tasks parameterized by cyclomatic complexity + API breadth.

2. **Ground-truth difficulty labels** (supervised): Ternary {easy, medium, hard} assigned by a deterministic oracle based on known difficulty parameters (step-count, complexity, domain rarity). These serve as the **supervised baseline labels**.

3. **Entropy-derived labels** (self-supervised): For each query, simulate k=5 Haiku completions by:
   - Drawing 5 response-quality scores from a Beta distribution whose parameters depend on ground-truth difficulty (easy → Beta(8,2), medium → Beta(4,4), hard → Beta(2,8)).
   - Computing normalized entropy H of the 5 scores (length-normalized).
   - Thresholding H into ternary labels using percentile boundaries (33rd, 67th).

   This captures the key mechanism: entropy is a noisy proxy for true difficulty, with confounds (creative/open-ended queries inflate entropy per CRIT-006).

4. **Confound injection** (addressing CRIT-006):
   - 10% of queries are flagged "open-ended/creative" with artificially inflated entropy regardless of true difficulty.
   - 5% of queries are "identical-failure" cases where all samples fail the same way, yielding low entropy despite high difficulty.

### Features

For each query, extract a 12-dim feature vector:
- `token_count` (int): query length in tokens
- `lexical_diversity` (float): type-token ratio
- `syntactic_depth` (float): parse-tree depth proxy (sentence length / clause count)
- `task_type_embedding` (4-dim): one-hot [factual, math, code, creative]
- `entropy_raw` (float): raw entropy of k=5 simulated completions
- `entropy_normalized` (float): entropy / mean_response_length
- `consistency_score` (float): fraction of 5 samples agreeing on answer
- `max_confidence` (float): max softmax-like score among 5 samples

### Router Model

**LightGBM classifier** (ternary: route-to-Haiku / route-to-Sonnet / route-to-Opus):
- `n_estimators`: 200
- `max_depth`: 6
- `learning_rate`: 0.1
- `num_leaves`: 31
- Class-balanced weighting (easy queries dominate)

### Experimental Arms

| Arm | Training labels | Features | Description |
|-----|----------------|----------|-------------|
| **Supervised (baseline)** | Ground-truth oracle labels | All 12 features | Upper bound — the "gold standard" router |
| **Self-supervised (proposed)** | Entropy-derived ternary labels | All 12 features | HYP-004's core claim |
| **Random baseline** | Uniform random ternary | All 12 features | Sanity lower bound |

### Evaluation Protocol

1. 70/15/15 train/val/test split, stratified by task type × difficulty.
2. Train each arm on train split, tune on val, evaluate on test.
3. Primary metric: `routing_accuracy_gap = acc(supervised) - acc(self_supervised)`.
4. Secondary metrics:
   - Per-task-type routing accuracy breakdown.
   - Label agreement between entropy-derived and oracle labels (to validate the labeling mechanism itself).
   - Cost ratio: fraction of queries routed to each tier.
5. Repeat for each of 3 seeds; report mean ± std.

### Success Criterion

`routing_accuracy_gap_vs_supervised ≤ 0.05` (mean across seeds). Per the pre-registered prediction in HYP-004.

### Ablation Trigger

If the main experiment passes, an auto-ablation will:
- **Remove the entropy signal**: train the self-supervised arm using only the 4 non-entropy features (token_count, lexical_diversity, syntactic_depth, task_type_embedding) with random labels to isolate whether entropy is the load-bearing mechanism.

### Known Limitations

- Synthetic data cannot perfectly capture real LLM entropy distributions; results are directional.
- k=5 is small for entropy estimation; real deployment might use k=10+.
- LightGBM is a simple router; neural routers (RouteLLM-style) may show different gaps.

### Code Skeleton

```python
#!/usr/bin/env python3
"""EXP: Self-supervised entropy-router vs supervised router."""

import json
import argparse
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score
import lightgbm as lgb

def generate_dataset(n=2000, seed=42):
    """Generate synthetic routing benchmark with oracle + entropy labels."""
    rng = np.random.default_rng(seed)
    
    # Task type distribution: 40% factual, 30% math, 30% code
    task_types = rng.choice([0,1,2], size=n, p=[0.4, 0.3, 0.3])
    
    # Ground-truth difficulty (0=easy, 1=medium, 2=hard)
    difficulty = np.zeros(n, dtype=int)
    for i in range(n):
        if task_types[i] == 0:  # factual
            difficulty[i] = rng.choice([0,1,2], p=[0.5, 0.3, 0.2])
        elif task_types[i] == 1:  # math
            difficulty[i] = rng.choice([0,1,2], p=[0.3, 0.4, 0.3])
        else:  # code
            difficulty[i] = rng.choice([0,1,2], p=[0.2, 0.4, 0.4])
    
    # Features
    token_count = rng.normal(50 + difficulty * 30, 15, n).clip(5)
    lexical_div = rng.beta(2 + difficulty, 5, n)
    syntactic_depth = rng.normal(3 + difficulty * 2, 1, n).clip(1)
    task_onehot = np.eye(4)[np.where(task_types < 3, task_types, 3)]  # 4-dim
    
    # Entropy simulation (k=5 completions)
    beta_params = {0: (8,2), 1: (4,4), 2: (2,8)}
    entropy_raw = np.zeros(n)
    consistency = np.zeros(n)
    max_conf = np.zeros(n)
    
    for i in range(n):
        a, b = beta_params[difficulty[i]]
        scores = rng.beta(a, b, 5)
        # Confound: open-ended queries inflate entropy
        is_creative = rng.random() < 0.10
        if is_creative:
            scores = rng.uniform(0.1, 0.9, 5)
        # Confound: identical-failure (low entropy despite hard)
        is_identical_fail = difficulty[i] == 2 and rng.random() < 0.05
        if is_identical_fail:
            scores = np.full(5, rng.beta(2, 8))
        
        probs = scores / scores.sum()
        entropy_raw[i] = -np.sum(probs * np.log(probs + 1e-10))
        consistency[i] = np.max(np.bincount(np.round(scores * 10).astype(int).clip(0,10), minlength=11)) / 5
        max_conf[i] = scores.max()
    
    resp_len = rng.normal(100 + difficulty * 50, 20, n).clip(10)
    entropy_norm = entropy_raw / (resp_len / 100)
    
    # Entropy-derived labels (ternary via percentile thresholds)
    p33, p67 = np.percentile(entropy_norm, [33, 67])
    entropy_labels = np.where(entropy_norm < p33, 0, np.where(entropy_norm < p67, 1, 2))
    
    features = np.column_stack([
        token_count, lexical_div, syntactic_depth, task_onehot,
        entropy_raw, entropy_norm, consistency, max_conf
    ])
    
    return features, difficulty, entropy_labels, task_types

def train_and_evaluate(X_train, y_train, X_test, y_test, seed):
    """Train LightGBM and return test accuracy."""
    model = lgb.LGBMClassifier(
        n_estimators=200, max_depth=6, learning_rate=0.1,
        num_leaves=31, class_weight='balanced',
        random_state=seed, verbose=-1
    )
    model.fit(X_train, y_train)
    preds = model.predict(X_test)
    return accuracy_score(y_test, preds)

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--seeds', nargs='+', type=int, default=[42, 137, 2024])
    parser.add_argument('--n-samples', type=int, default=2000)
    parser.add_argument('--output', type=str, default='result.json')
    parser.add_argument('--sanity', action='store_true')
    args = parser.parse_args()
    
    results = {'seeds': {}, 'summary': {}}
    
    for seed in args.seeds:
        features, oracle_labels, entropy_labels, task_types = generate_dataset(args.n_samples, seed)
        
        if args.sanity:
            # Sanity: just check supervised arm converges on 32 examples
            X_tr, y_tr = features[:32], oracle_labels[:32]
            model = lgb.LGBMClassifier(n_estimators=50, verbose=-1, random_state=seed)
            model.fit(X_tr, y_tr)
            train_pred = model.predict(X_tr)
            train_acc = accuracy_score(y_tr, train_pred)
            results['seeds'][str(seed)] = {'sanity_train_acc': float(train_acc)}
            if train_acc < 0.5:
                results['summary'] = {'sanity': 'FAIL', 'reason': f'train_acc={train_acc:.3f} < 0.5'}
                with open(args.output, 'w') as f:
                    json.dump(results, f, indent=2)
                return
            continue
        
        # Train/test split
        X_train, X_test, y_sup_tr, y_sup_te, y_ent_tr, y_ent_te, tt_tr, tt_te = \
            train_test_split(features, oracle_labels, entropy_labels, task_types,
                           test_size=0.15, stratify=oracle_labels, random_state=seed)
        
        # Arm 1: Supervised
        acc_sup = train_and_evaluate(X_train, y_sup_tr, X_test, y_sup_te, seed)
        
        # Arm 2: Self-supervised (entropy labels)
        acc_self = train_and_evaluate(X_train, y_ent_tr, X_test, y_sup_te, seed)
        
        # Arm 3: Random baseline
        rng = np.random.default_rng(seed)
        random_labels = rng.integers(0, 3, len(y_sup_tr))
        acc_rand = train_and_evaluate(X_train, random_labels, X_test, y_sup_te, seed)
        
        # Label agreement
        agreement = np.mean(y_ent_tr == y_sup_tr)
        
        gap = acc_sup - acc_self
        
        results['seeds'][str(seed)] = {
            'routing_accuracy_supervised': float(acc_sup),
            'routing_accuracy_self_supervised': float(acc_self),
            'routing_accuracy_random': float(acc_rand),
            'routing_accuracy_gap_vs_supervised': float(gap),
            'label_agreement': float(agreement),
        }
    
    if not args.sanity:
        gaps = [r['routing_accuracy_gap_vs_supervised'] for r in results['seeds'].values()]
        accs_sup = [r['routing_accuracy_supervised'] for r in results['seeds'].values()]
        accs_self = [r['routing_accuracy_self_supervised'] for r in results['seeds'].values()]
        results['summary'] = {
            'routing_accuracy_gap_vs_supervised': {
                'mean': float(np.mean(gaps)),
                'stddev': float(np.std(gaps)),
                'n_seeds': len(gaps),
            },
            'routing_accuracy_supervised': {'mean': float(np.mean(accs_sup))},
            'routing_accuracy_self_supervised': {'mean': float(np.mean(accs_self))},
            'hypothesis_confirmed': bool(np.mean(gaps) <= 0.05),
        }
    else:
        results['summary'] = {'sanity': 'PASS'}
    
    with open(args.output, 'w') as f:
        json.dump(results, f, indent=2)
    print(json.dumps(results['summary'], indent=2))

if __name__ == '__main__':
    main()
```
