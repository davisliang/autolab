## Summary

AutoMix generates an initial answer with the small LLM, then applies few-shot entailment-based self-verification to assess reliability. A POMDP router uses noisy verification probabilities to decide escalation. Learns from as few as 50 examples.

## Relevance to HYP-001

AutoMix is output-conditional (requires a cheap model call first), contrasting with HYP-001's pre-generation approach. It validates that lightweight routing decisions can achieve >50% cost savings. The POMDP formulation is elegant but adds latency from the initial LLM call.

## Gap

Does not study pre-generation query features. For tasks without context (pure memory QA), self-verification is unreliable — HYP-001's feature-based approach works for any query type regardless of context availability.
