## Cross-domain transplant rationale

Adaptive Bitrate (ABR) streaming (Netflix, YouTube) faces a structurally identical problem: decide video quality tier (240p → 4K) per segment with uncertain future bandwidth, maximizing UX without re-buffering. The BOLA algorithm maintains a virtual buffer score and applies Lyapunov optimization to pick the highest quality tier that keeps the buffer stable.

**Mapping to LLM routing:**

| ABR concept | LLM routing analogue |
|---|---|
| Video quality tier | Model tier (Haiku / Sonnet / Opus) |
| Bandwidth estimate | Rolling domain-difficulty estimate |
| Buffer occupancy | Rolling quality-cost balance score (QCBS) |
| Re-buffer penalty | Quality drop penalty |
| Throughput variance | Query difficulty variance in current batch |

The BOLA utility function `V·u(q) - p(q)` maps to `V·quality_estimate(tier) - api_cost(tier)` with V as budget-quality tradeoff.

## Mechanism

1. Maintain a rolling QCBS over the last 50 queries.
2. At each routing decision, solve per-query BOLA optimization: select tier `t*` maximizing `V·quality_estimate(t) - qcbs_penalty(t)`.
3. After each query, update QCBS with observed quality (from LLM judge on 10%-sampled outputs).
4. Compare against static threshold router re-calibrated only at epoch boundaries.

## Pre-registered prediction

After abrupt domain shift, quality degradation (relative to oracle) ≤ 3% within 50 queries.
Direction: **less**.

## Novelty

No prior work applies BOLA-style Lyapunov optimization to multi-tier LLM routing. Direct algorithmic transplant from the networking literature.

## Risks

- Quality estimation from 10% sampled judge calls may lag; evaluate latency of adaptation.
- V (budget-quality tradeoff) must be tuned per deployment context.
