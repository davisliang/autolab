## Summary

RouterBench is the first comprehensive evaluation framework for LLM routing. It provides 405k pre-computed responses from 11 LLMs across 8 tasks, a theoretical cost-quality framework, and results showing simple supervised classifiers can be competitive.

## Relevance to HYP-001

Validates HYP-001's core premise: (1) lightweight classifiers can route effectively, (2) cost variation across tiers makes routing worthwhile. The 405k dataset could serve as auxiliary training data. Formalizes routing accuracy as a metric, aligning with HYP-001's prediction.

## Gap

No ablation of query feature sets (does TTR or parse depth contribute beyond token count?). HYP-001's interpretable GBT would provide feature importance, filling this gap.
