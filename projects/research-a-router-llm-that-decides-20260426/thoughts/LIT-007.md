## Summary

Hybrid LLM (Microsoft, 2024) introduces a probabilistic router that predicts the quality gap between a small and large LLM. The router's threshold can be adjusted post-deployment but is not updated based on observed outcomes — it remains a static threshold.

## Relevance to HYP-003

Hybrid LLM represents the **static quality-aware router** paradigm: it models the routing problem well but has no feedback loop for online threshold re-calibration. This is exactly the mechanism HYP-003 adds via the QCBS rolling score.

The paper's test-time threshold adjustment is manual (requires the user to select a quality level), not automatic adaptation triggered by observed quality degradation after a domain shift.

## Gap identified

No automatic online re-calibration. Threshold adjustment requires manual intervention. No domain-shift robustness evaluation.
