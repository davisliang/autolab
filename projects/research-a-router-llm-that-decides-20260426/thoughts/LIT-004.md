## Summary

BOLA (Buffer Occupancy based Lyapunov Algorithm) is the foundational algorithm that HYP-003 proposes to transplant into LLM routing. It models video segment quality selection as a utility-maximization problem with a rebuffering penalty, then applies Lyapunov drift-plus-penalty optimization to derive a greedy per-segment policy.

## Relevance to HYP-003

HYP-003's core mapping is direct:

| BOLA concept | HYP-003 analogue |
|---|---|
| Buffer occupancy | Rolling Quality-Cost Balance Score (QCBS) |
| Bandwidth variance | Query difficulty variance |
| Rebuffer penalty | Quality drop penalty |
| Quality tiers (240p→4K) | Model tiers (Haiku→Sonnet→Opus) |

The key insight is that BOLA's Lyapunov framework allows **online re-calibration without predicting future inputs** — exactly the property needed for abrupt domain shift scenarios where query difficulty statistics change suddenly.

## Gap identified

BOLA was never applied to discrete LLM tier selection. No prior work adapts the BOLA utility function to a quality-cost balance score for language model routing.
