## Experiment Design: Latency-SLA-Aware EWMA Router

### Overview

This experiment tests whether augmenting a cost-optimal router with per-tier EWMA latency tracking and SLA-based override reduces P95 latency ≥25% vs. the cost-only router, while keeping mean quality within 2%.

### Simulated Environment

Since we cannot make real API calls to Haiku/Sonnet/Opus at scale, we simulate the routing scenario:

1. **Query generation**: 500 synthetic queries with ground-truth difficulty labels (easy/medium/hard) drawn uniformly. Each query is a dict with features: `token_count`, `lexical_diversity`, `difficulty_label`.
2. **Latency simulation**: Per-tier latency drawn from log-normal distributions calibrated to realistic API response times:
   - Haiku: μ=150ms, σ=80ms (fast, occasional spikes to 500ms+)
   - Sonnet: μ=400ms, σ=200ms (moderate, spikes to 1500ms+)  
   - Opus: μ=1200ms, σ=600ms (slow, spikes to 4000ms+)
   - Latency spikes are injected at random intervals (Poisson, λ=0.05) to simulate real bursty behavior.
3. **Quality simulation**: Each tier has a per-difficulty quality score drawn from a Beta distribution:
   - Haiku: easy=0.92, medium=0.70, hard=0.45
   - Sonnet: easy=0.95, medium=0.85, hard=0.70
   - Opus: easy=0.97, medium=0.93, hard=0.90
   - Quality jitter: ±0.03 uniform noise per query.

### Router Implementations

**Baseline (cost-only)**:
- Logistic scorer maps query features → tier probability
- Selects cheapest tier whose predicted quality exceeds threshold (0.5)
- Ignores latency entirely

**Treatment (EWMA-SLA)**:
- Same logistic scorer for cost-quality tier selection
- Maintains per-tier EWMA latency estimate: `L̂(tier) = α·observed + (1-α)·L̂_prev`, α=0.1
- Override rule: if `L̂(selected_tier) > SLA_threshold` (2000ms), downgrade to cheapest tier within SLA budget
- Quality guard: if ALL tiers exceed SLA, route to cheapest (Haiku) and flag as SLA-breached

### Metrics

1. **Primary: `p95_latency_reduction_ratio`** = 1 - (P95_treatment / P95_baseline). Hypothesis passes if ≥ 0.25.
2. **Secondary: `mean_quality_delta`** = mean_quality_treatment - mean_quality_baseline. Must be ≥ -0.02 (within 2%).
3. **Diagnostic: `tier_distribution`** — fraction of queries routed to each tier under each condition.
4. **Diagnostic: `sla_breach_rate`** — fraction of queries exceeding SLA threshold under each condition.

### Seeds and Reproducibility

Seeds [42, 137, 2026] control:
- Query difficulty sampling
- Latency distribution draws (including spike injection)
- Quality noise

All random state is seeded via `numpy.random.Generator(PCG64(seed))` for full reproducibility.

### Code Skeleton

```python
#!/usr/bin/env python3
"""EXP: Latency-SLA-aware EWMA router vs cost-only baseline."""
import argparse
import json
import numpy as np
from pathlib import Path
from dataclasses import dataclass, field

# --- Config ---
TIERS = ["haiku", "sonnet", "opus"]
LATENCY_PARAMS = {
    "haiku":  {"mu": 150,  "sigma": 80},
    "sonnet": {"mu": 400,  "sigma": 200},
    "opus":   {"mu": 1200, "sigma": 600},
}
QUALITY_PARAMS = {
    "haiku":  {"easy": 0.92, "medium": 0.70, "hard": 0.45},
    "sonnet": {"easy": 0.95, "medium": 0.85, "hard": 0.70},
    "opus":   {"easy": 0.97, "medium": 0.93, "hard": 0.90},
}
DIFFICULTIES = ["easy", "medium", "hard"]
N_QUERIES = 500
EWMA_ALPHA = 0.1
SLA_THRESHOLD_MS = 2000
SPIKE_LAMBDA = 0.05
SPIKE_MULTIPLIER = 3.0
QUALITY_JITTER = 0.03

@dataclass
class Query:
    idx: int
    difficulty: str
    token_count: int
    lexical_diversity: float

@dataclass
class EWMATracker:
    estimates: dict = field(default_factory=lambda: {t: LATENCY_PARAMS[t]["mu"] for t in TIERS})
    alpha: float = EWMA_ALPHA
    
    def update(self, tier: str, observed: float):
        self.estimates[tier] = self.alpha * observed + (1 - self.alpha) * self.estimates[tier]
    
    def predict(self, tier: str) -> float:
        return self.estimates[tier]

def generate_queries(rng, n=N_QUERIES):
    queries = []
    for i in range(n):
        diff = rng.choice(DIFFICULTIES)
        tok = int(rng.integers(10, 500))
        lex = float(rng.uniform(0.3, 0.95))
        queries.append(Query(i, diff, tok, lex))
    return queries

def sample_latency(rng, tier, spike_active):
    mu = LATENCY_PARAMS[tier]["mu"]
    sigma = LATENCY_PARAMS[tier]["sigma"]
    lat = float(rng.lognormal(np.log(mu), sigma / mu))
    if spike_active:
        lat *= SPIKE_MULTIPLIER
    return max(lat, 10.0)

def sample_quality(rng, tier, difficulty):
    base = QUALITY_PARAMS[tier][difficulty]
    return float(np.clip(base + rng.uniform(-QUALITY_JITTER, QUALITY_JITTER), 0, 1))

def cost_only_route(query):
    """Simple heuristic: easy→haiku, medium→sonnet, hard→opus."""
    return {"easy": "haiku", "medium": "sonnet", "hard": "opus"}[query.difficulty]

def ewma_sla_route(query, tracker):
    """Cost-optimal tier with EWMA-SLA override."""
    preferred = cost_only_route(query)
    if tracker.predict(preferred) <= SLA_THRESHOLD_MS:
        return preferred
    # Override: find cheapest tier within SLA
    for tier in TIERS:  # ordered cheap→expensive
        if tracker.predict(tier) <= SLA_THRESHOLD_MS:
            return tier
    return TIERS[0]  # all exceed SLA → cheapest

def run_simulation(seed):
    rng = np.random.default_rng(seed)
    queries = generate_queries(rng)
    
    # Pre-generate spike schedule
    spikes = rng.poisson(SPIKE_LAMBDA, N_QUERIES) > 0
    
    results = {"baseline": [], "treatment": []}
    tracker = EWMATracker()
    
    for i, q in enumerate(queries):
        spike = bool(spikes[i])
        
        # Baseline
        b_tier = cost_only_route(q)
        b_lat = sample_latency(rng, b_tier, spike)
        b_qual = sample_quality(rng, b_tier, q.difficulty)
        results["baseline"].append({"tier": b_tier, "latency": b_lat, "quality": b_qual})
        
        # Treatment (EWMA-SLA)
        t_tier = ewma_sla_route(q, tracker)
        t_lat = sample_latency(rng, t_tier, spike)
        t_qual = sample_quality(rng, t_tier, q.difficulty)
        tracker.update(t_tier, t_lat)
        results["treatment"].append({"tier": t_tier, "latency": t_lat, "quality": t_qual})
    
    return results

def compute_metrics(results):
    b_lats = [r["latency"] for r in results["baseline"]]
    t_lats = [r["latency"] for r in results["treatment"]]
    b_quals = [r["quality"] for r in results["baseline"]]
    t_quals = [r["quality"] for r in results["treatment"]]
    
    p95_b = float(np.percentile(b_lats, 95))
    p95_t = float(np.percentile(t_lats, 95))
    p95_reduction = 1.0 - (p95_t / p95_b)
    
    mean_q_delta = float(np.mean(t_quals) - np.mean(b_quals))
    
    sla_breach_b = sum(1 for l in b_lats if l > SLA_THRESHOLD_MS) / len(b_lats)
    sla_breach_t = sum(1 for l in t_lats if l > SLA_THRESHOLD_MS) / len(t_lats)
    
    tier_dist_b = {t: sum(1 for r in results["baseline"] if r["tier"] == t) / len(results["baseline"]) for t in TIERS}
    tier_dist_t = {t: sum(1 for r in results["treatment"] if r["tier"] == t) / len(results["treatment"]) for t in TIERS}
    
    return {
        "p95_latency_baseline_ms": p95_b,
        "p95_latency_treatment_ms": p95_t,
        "p95_latency_reduction_ratio": p95_reduction,
        "mean_quality_baseline": float(np.mean(b_quals)),
        "mean_quality_treatment": float(np.mean(t_quals)),
        "mean_quality_delta": mean_q_delta,
        "sla_breach_rate_baseline": sla_breach_b,
        "sla_breach_rate_treatment": sla_breach_t,
        "tier_distribution_baseline": tier_dist_b,
        "tier_distribution_treatment": tier_dist_t,
    }

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--seeds", nargs="+", type=int, default=[42, 137, 2026])
    parser.add_argument("--output-dir", type=str, required=True)
    parser.add_argument("--sanity", action="store_true")
    args = parser.parse_args()
    
    out = Path(args.output_dir)
    out.mkdir(parents=True, exist_ok=True)
    
    if args.sanity:
        # Sanity: run 32 queries, check that EWMA tracker converges
        rng = np.random.default_rng(42)
        tracker = EWMATracker()
        for _ in range(32):
            lat = sample_latency(rng, "opus", False)
            tracker.update("opus", lat)
        est = tracker.predict("opus")
        initial = LATENCY_PARAMS["opus"]["mu"]
        print(json.dumps({"sanity": "pass" if abs(est - initial) / initial < 0.5 else "fail",
                          "ewma_estimate": est, "initial": initial}))
        return
    
    all_metrics = []
    for seed in args.seeds:
        results = run_simulation(seed)
        metrics = compute_metrics(results)
        metrics["seed"] = seed
        all_metrics.append(metrics)
        print(f"seed={seed} p95_reduction={metrics['p95_latency_reduction_ratio']:.4f} quality_delta={metrics['mean_quality_delta']:.4f}")
    
    # Aggregate
    p95_vals = [m["p95_latency_reduction_ratio"] for m in all_metrics]
    qd_vals = [m["mean_quality_delta"] for m in all_metrics]
    
    summary = {
        "p95_latency_reduction_ratio": {"mean": float(np.mean(p95_vals)), "stddev": float(np.std(p95_vals)), "n_seeds": len(args.seeds)},
        "mean_quality_delta": {"mean": float(np.mean(qd_vals)), "stddev": float(np.std(qd_vals)), "n_seeds": len(args.seeds)},
        "per_seed": all_metrics,
    }
    
    (out / "result.json").write_text(json.dumps(summary, indent=2))
    print(f"\nAggregate: p95_reduction={summary['p95_latency_reduction_ratio']['mean']:.4f}±{summary['p95_latency_reduction_ratio']['stddev']:.4f} "
          f"quality_delta={summary['mean_quality_delta']['mean']:.4f}±{summary['mean_quality_delta']['stddev']:.4f}")

if __name__ == "__main__":
    main()
```
