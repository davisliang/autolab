## Motivation

Final-accuracy comparisons can mask early convergence speed differences. A model that reaches target accuracy 2 epochs sooner offers practical value (cheaper training, less overfitting risk) even if asymptotic accuracy is identical. This hypothesis tests convergence *rate* rather than asymptote.

## Mechanism

Run uniform SGD and the three layer-wise strategies (HYP-002, HYP-003, plus linear LR ramp from low→high across layers) for up to 30 epochs. Record the first epoch at which val_accuracy ≥ 0.97 for each. If a strategy never reaches 0.97, record NaN (counts as failure).

## Pre-registration

min(epochs_to_97pct, layer-wise strategies) < uniform_SGD_epochs_to_97pct − 2.0. Both must reach 97% for a valid comparison; if neither does, result is inconclusive.
